# Demo 说明（v2 交互演示）

> `workbench-demo.html` 是 v1 方案定稿后的**新布局完整交互演示**，供验收产品设计。
> 直接双击在浏览器打开（需与 `vue.global.prod.js` 同目录）。打开时会先弹出验收清单。
> 旧版 `ui-demo.html` 是 v0 布局（聊天居中），已被本演示取代，仅留作对照。

## 演示覆盖的设计决策（= 验收点）

| # | 决策 | 在演示里怎么看 |
|---|---|---|
| 1 | 布局：左收起 / 中舞台 / 右聊天 | 左栏是图标轨（点开浮层），舞台占最大区，右侧聊天驱动 |
| 2 | 三前置硬门：文稿→分镜→风格图 | 直接点发送后自动串到风格样张，**不点确认不会往下走** |
| 3 | 风格图 = HTML 样张，必须用户点头 | 舞台展示 2 张样张；「换一版」切换方向；聊天里有确认按钮 |
| 4 | 制作管线段状态 + 灰色占位时间轴 | 分镜表逐段变状态（配音中→画面生成中→检查中→渲染中） |
| 5 | 整条完成一次点亮 | 状态跑完后舞台才切到播放器+时间轴 |
| 6 | 布局：视频在上、时间轴在下（横竖屏统一，全宽） | 成片视图：播放器居中在上，深色专业时间轴全宽在下 |
| 7 | 四级寻址·段 / 秒帧 | 点时间轴视频轨的段块 → 📎 段N；点轨道空白处 → 暂停 + 📎 时间码 |
| 8 | 四级寻址·元素（命名元素） | 视频正下方大按钮「🔍 检视画面 · 点选元素修改」→ 悬停出人话名 → 点击成 📎 |
| 9 | 修改循环：改元素、重渲段 | 带 📎 说"改成珊瑚色" → 聊天显示三步修改、时间轴该段闪烁；也可嘴说"45秒那个箭头太慢" |
| 10 | 出片成本卡 + 方法库沉淀 | 「出片」→ 成本明细（LLM/TTS/渲染）→ 起草模板/经验卡 → 确认入库 → 左栏模板库出现 |

## 演示模拟（与真实实现的差异）

- 视频/旁白/字幕是**前端假播放**（无真实 MP4），但三轨结构、逐词高亮、播放头与真实设计一致；
- 检视模式固定展示"段3 瑞利散射"的示意帧（真实实现为加载该段活合成物 seek）；
- 制作耗时、成本数字均为演示值；
- Agent 回复为脚本编排（真实实现：ReAct 循环 + 状态机门禁，见 plan.md §4.7）。
